# 水金呼吸・回憶膠囊

> 把每一次相聚，留給未來的家人。

## 1. 目的與範圍

回憶膠囊是一個私密的家族媒體空間，保存照片、原始影片、文字回憶、留言與反應。它不取代好日子 x 相聚的活動報名功能；「陳水金家族皇宴」會是回憶膠囊的第一本相簿。

第一版的目的，是讓受邀家人能以已熟悉的 LINE 身分，在手機上快速瀏覽、上傳與留下回憶，不必建立新的帳密或填寫新的暱稱。

## 2. 已確認的產品決策

| 主題 | 決策 |
| --- | --- |
| 產品名稱 | 水金呼吸・回憶膠囊 |
| 成員身分 | LINE Login 是唯一身分來源 |
| 顯示名稱 | 直接使用 LINE 公開暱稱與頭像；不設自訂家族暱稱步驟 |
| 登入便利性 | 裝置與 LINE 的 Face ID／Touch ID 負責安全確認；網站不處理生物辨識 |

| 發布方式 | 受邀成員上傳後立即顯示；後續管理而非逐筆審核 |
| 影片第一版 | 直接保存並播放原始 MP4／MOV；後續再評估轉檔與多畫質串流 |
| 第一顆膠囊 | 陳水金家族皇宴 |
| 備份 | 僅總管理者可下載家族或單一膠囊 ZIP；含原始媒體與 metadata，單次 2 GB 內直接串流，較大範圍分膠囊下載 |

## 3. 使用者與權限

### 家族成員

- 以邀請連結加 LINE Login 進入。
- 瀏覽全部已發布的膠囊、照片、影片與留言。
- 上傳照片、影片，建立文字回憶，留言與按愛心。
- 修改或刪除自己的內容。
- 回報想移除或不適合的內容。

### 膠囊管理者

- 擁有家族成員的全部能力。
- 建立、編輯、排序、封存膠囊，設定封面與前言。
- 移動、隱藏、恢復或刪除任何媒體與留言。
- 處理回報、管理成員及共同管理者。

### 總管理者

- 管理家族邀請連結、存取權限與 R2 用量。
- 匯出備份與處理永久刪除。

## 4. 第一版畫面與功能

### 家族首頁

- 家族名稱、封面、簡短介紹與「新增回憶」主要按鈕。
- 最新回憶：最近上傳的媒體、文字與留言。
- 膠囊列表：封面、名稱、日期／年代與內容數量。
- 最近留言與家族公告。

### 膠囊頁

- 封面、名稱、日期／年代、前言與建立者。
- 照片與影片瀑布流；點選可開啟完整檢視。
- 膠囊留言板。
- 管理者編輯、封存與排序操作。

### 媒體與回憶

- 手機多選照片、直接影片上傳、上傳進度與失敗重試。
- 每則媒體可有標題、拍攝日期、人物／事件描述與回憶文字。
- 顯示 LINE 暱稱、頭像、上傳時間、留言與愛心。
- 每張照片、每支影片均可留言；膠囊本身也有留言板。
- 支援「代替長輩留言」，顯示例如「王阿嬤（由小阿姨代傳）」並保留實際操作者記錄。

### 成員與安全

- 首次使用必經有效家族邀請連結與 LINE Login；之後保留安全登入工作階段。
- 明顯顯示目前登入的 LINE 暱稱與頭像，並提供切換帳號／登出。
- 管理者可撤銷邀請、停用成員與新增共同管理者。

### 管理後台

- 膠囊、媒體、留言、回報與成員總覽。
- 隱藏、恢復、移動與刪除內容；刪除內容先進保留區 30 天。
- 儲存容量、相簿用量、80%／90% 容量提示與備份匯出。

## 5. 發布與管理規則

1. 已登入的受邀家人發布後立即顯示，不等待管理者審核。
2. 所有媒體與留言可被回報；管理者可隱藏而不立即永久刪除。
3. 保留誰建立、修改、隱藏、恢復與刪除內容的稽核紀錄。
4. 已刪除內容先保留 30 天，期限過後才由管理者或保留政策永久清除。
5. 不公開搜尋、不提供未登入存取，亦不提供永久有效的原始媒體網址。

## 6. 媒體規則與初始限制

| 類型 | 第一版限制 | 備註 |
| --- | --- | --- |
| 照片 | 單檔預設上限 20 MB | 原檔與縮圖分開保存 |
| 影片 | 單檔預設上限 1 GB 或 15 分鐘 | 先支援 MP4／MOV；管理者可調整 |
| 影片播放 | 原始檔直播放或下載 | 不保證所有格式／裝置皆可串流 |
| 容量 | 預設 20 GB；80% 與 90% 告警 | 達上限時拒絕新上傳；管理者日後可調整 |

## 7. 不納入第一版

- 額外帳密、網站 Passkey 或自訂會員系統。
- 人臉辨識、人物自動標記與 AI 相片分類。
- 自動影片轉檔、多畫質自適應串流與剪輯。
- 即時聊天室、公開分享或跨家族分享。
- 逐筆上傳審核。

## 8. 驗收標準

- 家人可在 iPhone、Android、LINE 內建瀏覽器及一般瀏覽器使用 LINE Login 進入。
- 每則內容都有可追溯的 LINE 身分、顯示名稱與時間。
- 未登入與被停用的成員無法取得私有媒體。
- 受邀成員可在手機完成上傳、觀看、留言與刪除自己的內容。
- 管理者能復原誤隱藏內容、處理回報、查看容量並完成資料匯出。
